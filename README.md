# Projet IoT - iot_by
## Présentation
Ce dépôt regroupe les fichiers et les travaux du projet IOT.
## Objectifs
- Organiser les sources et les ressources du projet.
- Conserver l'historique des modifications avec Git.
- Synchroniser le travail avec GitHub.
## Organisation du dépôt
- `README.md`: présentation du projet et consignes.
-`.gitignore` : fichiers exclus du suivi Git.
## Prérequis
- Git Arduino SimulIDE installés.
- Les outils nécessaires au projet, selon les fichiers utilisés.
## Utilisation
1. Cloner le dépôt ou récupérer les fichiers.
2. Lire les consignes du projet.
3. Compiler les sources et téléverser sur un objet dédié
